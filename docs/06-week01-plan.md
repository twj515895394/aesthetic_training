## 本周目标

在不了解作者解说前，能够描述第一眼看到的对象，找出至少一项可观察的视觉原因（明暗、颜色、位置、线条、形状、清晰度、人物眼神等），用图片修改验证自己的判断。

每天一主案例、一跨领域对照案例；Day 7 为复盘例外。建议执行 25 分钟五步闭环，不做大规模素材搜集。具体开课时必须检查主/对照案例是否都能够支持本周研究问题；反例按需融入 1+1，不为凑数量添加作品。

## D01 演示题（首轮脚本示例）

1. 请用一句话说出你第一眼看到了什么，不要预先看解说。
2. 你认为视线被吸引，主要由于亮度、颜色、线条、位置还是动作？用画面证据回答。
3. 对比另一种媒介里的自然光人物画面，判断相似之处与差异。
4. 在同一图上做一个遮挡或裁切小实验，看视觉焦点是否改变。
5. 记录“我的初始判断 / 后来发现 / 实验后的新判断 / 有哪些不确定”。
