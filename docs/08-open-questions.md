## Q-001｜每日反馈与纠错机制

**要解决的问题**：当学员回答一张画面的视觉焦点或完成一个改图实验时，AI 应先指出缺点、先让学员自评，还是进行交替诊断？这会直接影响独立审美判断与实际学习效果。

**拟讨论三个方案**（尚未确认）：

- **A 立即点评**：每次回答后教练直接给出结构化反馈，效率高，但可能削弱自我发现。
- **B 自评与证据优先**：学员先自评，教练用反问引导；能锻炼独立性，但可能耗时。
- **C 分级反馈（推荐）**：初学知识点先做轻量示范与即时纠偏；熟悉后先自评和证据解释；最后提供具体事实、主观解释和改进建议的区分，必要时示范修改。兼顾 20–30 分钟内的节奏。

**推荐 C 的原因**：与已确认的混合教学、分层实战保持一致，并为后续建立个性化错因/复盘记录留出结构。但**在用户选择前不算已确认决策**。
