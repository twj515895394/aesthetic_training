## Q-001｜每日反馈与纠错机制（已解决）

**结论：C 分级反馈，已确认（D-011）。** 初学知识点进行适量示范、即时纠偏；熟悉后优先让学员自主解释证据；教练提供针对性反馈，区分画面事实、可辩论的解释与改进建议。是否评分、精确反馈字段、追问轮次上限仍待后续细化。

## Q-002｜每日训练记录的最小字段与填写负担（已解决）

**结论：C 双层记录 + AI 辅助整理，已确认（D-012）。** 学员先独立表达观察、自评及依据；AI 整理真实对话、案例出处和实际实验为 Markdown 草稿；学员审核后才进入 GitHub。不得把 AI 推断包装成学员原话，也不得补造缺席的训练事实。具体元数据字段、命名与自动化触发细节可日后依据实操微调。

## Q-003｜学习成果评价与阶段进阶机制（已解决）

**结论：C 证据驱动的混合评估，已确认（D-013）。** 每日保存真实观察与实验；每周独立分析陌生作品并完成一次知识迁移；W04/W08/W12 把早期与近期证据并排分析。观察证据、解释能力、表达意图、改造结果和跨领域迁移是关注维度；仅在有必要时用轻量等级辅助跟踪，不以主观风格偏好给出“审美分”。细节见 [09 评估与复盘机制](09-assessment-and-review.md)。

## Q-004｜难度自适应与薄弱项复习（已解决）

**结论：C 固定主线 + 薄弱项补练 + 逐步加难，已确认（D-014）。** 继续推进 12 周主题和 4+2+1 周节奏；根据真实训练记录，在当前主案例、对照或练习内嵌入先前薄弱知识点，不另增训练时长；掌握后逐步减少提示、引入陌生案例及跨领域迁移/创作。细节见 [10 自适应训练规范](10-adaptive-training.md)。触发阈值、复习占比与难度等级仍属待定参数。

## Q-005｜案例获取、来源核验与入库流程（已解决）

**结论：C 小型基础案例库 + 按课即时补充，已确认（D-015）。** 按周主题和领域准备少量有可靠来源的候选案例；训练中选 1 张主案例与 1 张不同领域对照；实际使用后再保存案例卡，记录作者/作品/原始出处/研究用途/授权状态。个人图片随时进入候选；无公开再分发许可的第三方作品只存来源链接及自写分析。候选库规模、质量评分、详细字段仍是实施细节，不预设未经确认的数量。详见 [11 案例获取与积累](11-case-acquisition.md)。

## Q-006｜案例图片与实战素材如何存储（已解决）

**结论：D-016 本地优先，已确认。** 用户会把仓库 clone 到本地；大部分素材在本地管理，不考虑同步大文件到 GitHub。GitHub 以 Spec、案例卡、知识卡、训练记录等 Markdown 为核心；建议本地二进制媒体统一放 `local-assets/`，由 `.gitignore` 默认排除。资料卡可记录可信原始来源 URL 和仓库相对的 `local_media` 路径，便于本地定位；远程网页不展示本机文件属于预期行为。无需先引入 Git LFS、云端对象存储或远程资产系统。具体约定见 [12 本地媒体管理](12-local-asset-storage.md)。

## Q-007｜案例、知识与练习的索引复用（已解决）

**结论：C Markdown 元数据 + 标签 + 交叉关联，已确认（D-017）。** 以稳定的案例/知识点/训练 ID 和 YAML front matter 建立可检索关联，正文提供双向 Markdown 导航链接；远程保存文本索引和可分享的出处，本机媒体只记录相对路径；先用分类索引页与全文搜索，随着真实规模增加再讨论脚本生成或专用 UI。字段细则见 [13 元数据与索引规范](13-metadata-and-indexing.md)。

## Q-008｜每日课程如何启动、续接与补课（已解决）

**结论：C 进度驱动的课程会话，已确认（D-018）。** 用 `Wxx-Dxx` 实际完成序号而非自然日期决定下一节，用户主动开始/继续/查询进度，未完成会话保留真实进展与待办；漏学不自动跳过。每周的 D01–D06 完成后可开始 D07 复盘，审核归档 D07 后才进入下一周。独立对话须先读取持久化进度记录，不能凭空声称记得中断位置。精确状态字段是首版建议，见 [14 课程会话与进度管理](14-session-and-progress.md)。

## Q-009｜提醒与周期汇报（已解决）

**结论：A 完全手动，已确认（D-019）。** 用户主动发起训练、续接及回顾；不设自动提醒、不定期推送自动报告。需要总结时，根据已完成且经审核的记录即时提供即可。

## Q-010｜高质量训练案例的来源构成（已解决）

**结论：C 经典标杆 + 当代优秀作品 + 必要反例，已确认（D-020）。** 案例按当天训练目标精选，优先作品真伪和出处可查、可见的视觉结构、可对照性及可动手验证；经典标杆建立观察基准，当代作品帮助应用，反例说明适用边界。并非每天机械要求三张图：普通课程仍沿用 1 主 + 1 跨领域对照，反例可作为其中一张、局部变化或其他课次专门分析，不增加负担。选材原则见 [11 案例获取与积累](11-case-acquisition.md)。

## Q-011｜选材责任与质量把关（已解决）

**结论：C AI 负责精选与轻量自检，学员可随时替换，已确认（D-021）。** AI 在开课前核对作品与出处、视觉可读性、教学目标、主案例与对照案例的共同研究问题；不要求学员事前逐张批准。学员有权指出选材不足，要求换图或提供个人作品。来源不清、画面无法确认的图不能冒充合格素材。沿用 [11 选材规范](11-case-acquisition.md)，不新增工程系统。

## Q-012｜上课时案例图片如何展示（已解决）

**结论：C 直观画面优先 + 官方出处备查，已确认（D-022）。** 开课优先在课堂中直接展示主案例及跨领域对照，让学员能辨识细节并比较；同时提供可信的原始作品来源。若内嵌画面因技术或授权原因无法可靠显示，改为能看清图片的官方作品页并确认可观察，或替换同等教学价值作品。不把看不到的图片当成已看过，不用失效链接或低清缩略图凑数。D-016 的本地文件不上传 GitHub 原则不变。

## Q-013｜如何开始第一轮真实训练（下一轮）

**问题**：主要教学与选材原则已确认，是否还要继续设计大量细则，还是尽快用真实作品测试一节课程，实际检验视觉质量与学习收获？

**选项**：

- **A 继续完善全部训练细则再开课**：计划更全面，但会推迟真实学习，也可能过度工程化。
- **B 直接按现有第一周草案连续开课**：马上进入正式训练，但如果 D01 选图不理想，容易把问题带入后续课次。
- **C 先进行 W01-D01 实战试课（推荐）**：由 AI 选一组实际核验的优质主/对照案例，依 D-022 在课堂展示或提供可观察的权威来源，按 20–30 分钟完成真实观察、比较与小实验；结束时根据实际体验简要调整 W01 后续选材，用户审核记录后归档。这是**真实训练而非虚构示范**，未完成不计入已完成进度。

**推荐理由**：最少讨论、最快验证关键价值，也能把精力转向素材和教学本身。只有用户真正发起训练才将进度改为进行中。
