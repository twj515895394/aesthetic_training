## Q-001｜每日反馈与纠错机制（已解决）

**结论：C 分级反馈，已确认（D-011）。** 初学知识点进行适量示范、即时纠偏；熟悉后优先让学员自主解释证据；教练提供针对性反馈，区分画面事实、可辩论的解释与改进建议。是否评分、精确反馈字段、追问轮次上限仍待后续细化。

## Q-002｜每日训练记录的最小字段与填写负担（下一轮）

**要解决的问题**：怎样既能留存主案例、对照、实验、个人判断、教练反馈，便于复盘检索，又不因手动填写而挤占 20–30 分钟的学习时间？

**候选方案（尚未确认）**：

- **A 完整手填**：每天亲自填全部模板字段；最完整，但可能耗时。
- **B AI 自动总结为主**：教练生成整份训练笔记，学员只确认；省事但可能弱化自己的思考，存在错记风险。
- **C 双层记录（推荐）**：学员只需写核心观察、自评和选择依据；AI 把本次互动、素材来源、实验信息整理成标准 Markdown 草稿；学员审核后再入库。分“必填精简记录”和“可选详细研究记录”，杜绝未经确认的自动结论。

**待确认**：由用户在下一轮 Grill 选择方案。
