## 4. 变更规则

1. 新问题出现先登记为 `待讨论`。
2. 用户明确选择后变为 `已确认`，注明理由和对应文档。
3. 若新决策与旧决策冲突，明确记录“替代了 D-xxx”，不得无痕改写历史。
4. 训练中的主观审美观点写作「观察/假设」，除非已经有明确适用边界，不要冒充科学定律。
