# 09｜学习成果评估与复盘机制

> 决策编号：**D-013（Q-003）** · 状态：**已确认核心机制 C「证据驱动的混合评估」**。具体量表分级、打分权重与进阶门槛尚未 Grill 决定；自适应补练的**总体机制 C 已确认（D-014）**，参数仍待决定。

## 1. 核心理念

审美训练不以学会多少术语、背诵多少“标准构图”或迎合 AI 的个人喜好为进步依据。评价要追踪：**看到什么（观察）→ 有什么依据（判断）→ 想表达什么（意图）→ 做出什么改动（实践）→ 能否用到陌生领域（迁移）**。

允许存在不同的有证据的艺术解读。要区分事实与解释：主体在画面左侧是可观察事实；它“显得孤独”是需要画面依据、也可能因语境而异的解释。

## 2. 三层证据机制（已确认）

| 频率 | 检验任务 | 需要保存的证据 | 不能替代的内容 |
|---|---|---|---|
| 日常 | 主案例观察、跨领域对照、一个合适层级的实验 | 学员的第一判断与观察依据；实战的目标、改动和真实结果；AI 有根据的反馈 | AI 生成的“正确答案”不能替代学员独立思考 |
| 每周（Day 7） | **未分析过的陌生案例**独立判断 + 一个**跨领域迁移**任务 | 原始独立分析、对照案例与实践效果、修正后的结论、未解决的问题 | 重复刚讲过的作品不能充当陌生案例 |
| 阶段（W04 / W08 / W12） | 将**早期与近期案例分析/作品**并排回顾，必要时增加陌生案例 | 早期与近期的训练链接、标注/裁切/改图结果、反思、迁移表现 | 不得凭空声称“进步明显”而无可检查的前后证据 |

每周复盘仍使用已经确定的**每周第七次课**（D07）训练时段，不新增固定课外时间；该课时在 D01–D06 实际审核完成后启动，不等同于自然周日。阶段对照资料较多时，可提前在当周日常训练里逐步收集。

## 3. 建议观察维度（框架已确认；刻度尚未确认）

1. **观察能力**：能否识别焦点、层级、明暗、色彩、线条、空间等与任务有关的视觉关系。
2. **证据与解释能力**：能否指出具体画面证据，解释为什么产生某种视觉感受；能否承认有多种合理解读。
3. **表达意图能力**：能否把目标（例如“更宁静”）转成具体的视觉操作策略。
4. **视觉改造能力**：能否控制变量、比较前后效果、解释改动是否接近目标。
5. **跨领域迁移能力**：能否将一种方法运用到陌生媒介或新的案例，并识别失效边界。

**评价约束**：可用简单能力等级辅助记录趋势，但每项都应附作品/原始回答证据链接；不对风格偏好、题材喜好或“艺术价值”给无依据的统一分数。

## 4. 日常与每周的操作闭环

### 日常（由 D-012 双层记录支持）

- **学员层**保留：未被教练引导前的第一判断、依据、实验决定、自评和不确定之处。
- **AI 整理层**保留：当日原作和对照来源、相关概念、练习参数/版本、教练依据与建议。
- **最终文档**由学员审阅后才进入仓库，避免将 AI 的解释误算作学员独立成果。完成状态与下一课时由 [D-018 进度规则](14-session-and-progress.md) 管理，不以日历推断。

### 周复盘

- 用陌生作品检验学员是否能脱离已讲过的图片独立观察。
- 用不同领域的小实践检验知识是否真正迁移，而不只能够说出术语。
- 以“本周做得更好的具体证据 / 仍不确定的结论 / 下周要验证的点”形成简短总结。
- 发现薄弱环节后，按照 **D-014 固定主线 + 动态强化**，在后续现有案例与实战中安排旧知识复现；对熟悉知识降低提示、增加陌生案例和跨领域迁移。补练比例、触发条件及量表细节仍待讨论。

### W04 / W08 / W12 阶段回顾

- 选择早期与当前的同类任务或具有可比目标的任务，不因图片题材不同而机械排名。
- 记录有哪些变化确实可见（例如同一构图目标下更有意识地控制画面焦点），并注明其他影响因素。
- 区分“知识记忆改善”“提示依赖降低”“实际画面控制能力增强”三种不同结果。
- 记录下一阶段建议，但不使用尚未批准的硬性晋级标准。

## 5. 推荐保存的复盘产物

- 每日：`practices/daily/Wxx-Dxx-*.md`
- 每周：`practices/reviews/Wxx-review.md`（模板：[weekly-review.md](templates/weekly-review.md)）
- 阶段：建议 `practices/reviews/W04-checkpoint.md` 等（命名仍可调整）。
- 作品证据：具有适当上传权限时附前后图片；否则使用带来源的外部链接以及文字化改动说明。
