# 02｜十二周首轮学习研究路线

状态：**阶段结构及周主题已讨论，作为当前路线草案使用**；每周作业细则可随实践调整。12 周是第一轮，不是终点。

## 1. 两条维度交叉

- **能力线（横向）**：视觉焦点 → 层级/平衡 → 构图 → 空间 → 光影 → 色彩 → 风格/媒介 → 视觉表达。
- **领域线（纵向）**：电影画面、摄影、绘画、插画、平面设计、广告、空间/建筑、产品/生活美学。
- **课程策略**：各周围绕一个能力主题；每天主案例与对照案例来自不同领域，避免“电影一周、摄影一周”变成割裂的课程。

个人案例包含自己拍摄、收藏或创作的作品，不仅限于 AI 作品。无个人图片时，允许先从合法参考案例中自选，以免中断训练。

## 4. 时间和学习负荷（已确认）

- 每天 20–30 分钟；建议以 25 分钟为启动版本。
- 每个普通训练日一主案例 + 一跨领域对照；周复盘可以使用旧案例及少量新测试图，无需机械重复 1+1。
- 每次实战从三级方案选择合适层级，不强制把观察、单变量实验、完整复刻全部做完。
- 避免为完成打卡堆砌素材；每次至少留下一个**可核查的判断或改动结果**。

## 5. 证据驱动的复盘与阶段评估（D-013 已确认）

- **日常**：保留个人的第一判断与证据、实战目标、关键修改及真实结果；AI 的补充解释与学员观点分开记录，学员审核后归档。
- **每周复盘日**：选一张未分析过的陌生作品，独立描述视觉关系和依据；再完成一个跨领域迁移的小任务，避免只会回答看过的案例。
- **W04 / W08 / W12 阶段回顾**：以早期与近期记录、改图版本和陌生任务为依据，比较观察能力、解释能力、视觉表达意图、改造效果和知识迁移情况。
- **判断方法**：以文字和图像证据为主，必要时辅助轻量能力等级；不对艺术风格、喜好或情绪解读给“唯一正确的审美分”，不设置未经讨论的强制晋级阈值。
- **容量限制**：周复盘仍占每周第七天 20–30 分钟；深入阶段评估如需更多材料，可在 W04/W08/W12 相应周内分散收集，不必临时加时。

具体取证、复盘和仍待定细节详见 [09 评估与复盘机制](09-assessment-and-review.md)。

## 6. 固定主线与自适应强化（D-014 已确认）

- **主线固定**：W01–W12 的每周知识主题、4 天精选案例 + 2 天个人案例 + 1 天复盘安排不因短期表现而自动取消或跳过。
- **发现薄弱点**：根据日常原始观察、实验结果与每周陌生案例/迁移表现找到尚未掌握的知识；将它写进下一周练习建议，而不是仅用模糊的“审美还不够”。
- **补练方式**：在下一周主题的主案例、跨领域对照或个人作品实战中嵌入旧知识，优先一题兼顾新旧能力，不增加每天 20–30 分钟的训练时长。
- **逐步加难**：如果能独立完成当前任务，就减少 AI 提示、换陌生作品、增加干扰因素或让学员自主确定视觉目标，并检验跨领域迁移。
- **边界**：不因为 AI 猜测就标记“掌握/未掌握”，必须附训练记录证据；具体补练比例、难度等级和触发标准后续讨论。

详细规则：[10 自适应训练规范](10-adaptive-training.md)。

## 7. 依赖关系

W01/W02（看到什么）是 W03–W06（如何控制画面）的基础；前六周帮助在 W07–W10 研究风格与媒介而非停留在“好看”；W11/W12 将知识用于有意图的创作。即使在第一阶段也会用来自多个艺术领域的案例。
