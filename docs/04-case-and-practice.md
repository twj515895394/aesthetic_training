# 04｜案例组织与分层实战规则

状态：**案例来源 C、每日方案 B、实战方案 C 均已确认**。

## 1. 案例来源

- **AI 精选经典案例**：用于建立跨文化、跨时代、跨媒介的基本视觉观察样本。
- **个人案例**：自己拍摄、创作、收藏、正在设计或想改进的图片；并不要求都是 AI 生成。
- 每周建议并已在讨论中接受为：**4 天经典/精选 + 2 天个人 + 1 天复盘**。

## 2. 每日案例配对规则

每个普通训练日采用 **1 个主案例 + 1 个跨领域对照案例**。

1. **同一个视觉问题**：例如“留白如何改变孤独感”。
2. **不同领域**：主案例用水墨画，对照用建筑摄影；或主案例用人像摄影，对照用电影剧照。
3. **可比维度清晰**：注意力、对比、视觉层级、情绪或空间，不要求风格看起来相似。
4. **一主一辅**：主案例用于详细拆解和练习，对照案例用于验证知识是否可迁移；不做两个独立的完整课程。
5. **兼顾反例**：选一些不遵循常规“好看”规则但表达有效的作品，避免教条化。
6. **出处可靠、权利清晰**：记录作者、作品、出处、链接和许可；无可再分发授权时仅保留链接和自己的笔记。

周复盘日不强制补充两张新案例，应以复习、盲测、迁移为主。

## 3. 三级实战（已确认采用 C）

### Level 1｜观察与标注

- 典型任务：圈视觉焦点、标前中后景、遮挡元素、标引导线、提取主要色块、简单裁切。
- 核心目标：准确识别画面中已经存在的关系。
- 可交付：标注图、裁切版本、文字假设，至少一种。

### Level 2｜单变量实验

- 典型任务：同一图像只改变主体位置、留白量、光线方向、饱和度或标题层级中的**一个**变量。
- 核心目标：比较变量变化与视觉结果间的关系，明确什么变化带来了什么效果。
- 记录格式：`目标 → 保持不变项 → 改动项 → 前后观察 → 局限`。

### Level 3｜复刻与独立创作

- 典型任务：手机复刻布光；重构海报层级；AI 辅助制作同构图作品；按主题自主创作一组图片。
- 核心目标：将分析结果转化为主动视觉选择；不是“让模型自由生成一个漂亮画面”。
- 记录格式：`表达意图 → 视觉方案 → 具体执行 → 结果自评 → 下一轮修改`。

## 4. 层级选择原则

- **普通训练日**：优先 Level 1/2，确保每天完成一个小闭环。
- **个人案例日**：优先结合自己的作品做 Level 2/3。
- **每周复盘**：选择一个学过的原理，在未训练过的图中应用。
- **不是线性升级考试**：即使到了 W12 也可以为了检验基础而做 Level 1；不会要求每天三级全做。

## 5. 示例｜研究“留白”

- 主案例：绘画里大面积未绘区域如何烘托主体。
- 跨领域对照：摄影中空旷建筑与小人物的尺度关系。
- Level 1：圈出主体与留白，描述第一眼视线走向。
- Level 2：裁掉画面 30% 留白并对照情绪变化（30%为演示值，不是固定规范）。
- Level 3：自行拍摄窗边人物或静物，尝试以留白制造安静感。
- 结论须附具体观察，不要写成“留白越多越高级”。

## 6. 运行注意

- AI/手机/裁切工具都可用，但始终由学员给出视觉目标或最终判断。
- 个别艺术风格与情绪不等同于可被自动化评分的技术指标。
- 如使用生成工具，记录模型/提示词/版本的必要信息，防止无法复现；细节字段仍待讨论。
