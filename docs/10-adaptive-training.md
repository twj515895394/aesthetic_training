# 10｜自适应训练：固定主线 + 薄弱项补练 + 逐步加难

> 决策编号：**D-014（Q-004）** · 已确认：**C 方案**。核心机制已生效；具体数值阈值、难度刻度和补练占比仍是**待讨论参数**，不能当成已经批准的规则。

## 1. 解决什么问题

首轮有 12 周跨领域学习路线，每天只投入 20–30 分钟。固定课程可能让旧知识盲区不断累积；完全根据成绩改变主题又会破坏跨领域的覆盖范围。本机制让课程**在固定骨架内灵活调整当天练习**，不把审美训练变成死板的标准化考试。

## 2. 不变项（已确认）

- **12 周主线不变**：每周原定主题原则上继续推进，不因某个知识点暂时薄弱就自动跳过或无限延期。
- **每周 4+2+1 不变**：4 天精选案例、2 天个人案例、1 天复盘。
- **普通训练日 1+1 不变**：一张主案例和一张不同领域的对照案例，共同研究当天的视觉问题。
- **每天 20–30 分钟不变**：补练和加难安排在现有时间内，不额外增加固定课程。
- **证据优先**：依据 D-013 的原始观察、目标与改图结果，而不是只因为教练“感觉学员水平不够”就改课程。

## 3. 动态调整逻辑（已确认）

### 3.1 当某个旧知识点尚未掌握

1. 从每日原始记录或周复盘中找到**明确的困难及对应证据**（如“不能指出画面主次的理由”，而非“审美差”）。
2. 下一次选材时优先寻找能够**同时体现新主题与旧弱项**的案例；不为补练另建完整课程。
3. 设计一个短练习：让学员自己再判断一次旧知识在新作品中的表现，必要时回看知识卡。
4. 比较复练结果，仍有疑问则记录下来；不根据单次答错推断永久不掌握。

**例子**：W05 主线是光影，W02 的视觉平衡尚不稳定。选择一张侧光人像主案例，研究光影如何改变画面视觉重心；再用平面设计作品作跨领域对照。当天依然在学习光影，同时复习视觉平衡。

### 3.2 当某个知识点已较熟悉

在不增加每日时长的前提下，优先增加认知挑战而不是增加图片数量：
- 减少引导性问题与提前讲解，让学员先独立观察。
- 使用从未分析过的案例，避免单靠记忆复述。
- 引入含有冲突、反例或复杂元素的作品，要求说明理由与表达目标。
- 把同一视觉原理迁移到另一媒介，或让学员自主决定并实施一个改图目标。

“已熟悉”须有本人不依赖提示的观察和实践证据支持，不等于用户喜欢某种画风。

## 4. 每周调整的输入与输出

**输入**：本周的原始判断、教师纠偏记录、标注/裁切或其他实验版本、陌生案例表现、跨领域迁移结果。

**处理**：保持下一周主题，挑出一两个值得继续追问的能力问题作为**建议**，在每天主案例、对照或个人练习中体现；何时触发、每周允许多少项属于后续参数决策。

**输出**：周复盘记录：
- 下周主线主题；
- 旧弱项及链接证据；
- 可融入下一周主题的复习机会；
- 可以适度增加的难度及其理由；
- 是否需要教师示范、减少提示或自由创作；
- 学员审核后的最终计划。

现有模板：[每周复盘模板](templates/weekly-review.md)。

## 5. 与已有规则的兼容

| 已确定设计 | 本规范的兼容方式 |
|---|---|
| D-007 混合式教学 | 新概念可示范，熟悉概念优先自主判断 |
| D-008 1 主 + 1 跨领域对照 | 优先使用同一案例对照同时覆盖新旧知识 |
| D-009 三级实战 | 根据目标选标注 / 单变量实验 / 复刻创作，不强迫每日升级 |
| D-011 分级反馈 | 需解释具体观察依据，而非简单批评审美偏好 |
| D-012 双层记录 | 学员原始判断与 AI 诊断分开，AI 不得杜撰掌握情况 |
| D-013 证据驱动评估 | 每周的变化要能指回具体作品、记录或实验 |

## 6. 不允许的自动行为

- 因一次回答不理想就跳过已确认的本周主课题；
- 无依据地把“偏好不同”认作理解错误；
- 通过加时、加课或无限追加图片让用户补足薄弱项；
- 仅因 AI 给出一个结论就认定用户已经掌握；
- 不经学员审核就把教练提出的补练方案写成已完成的学习成果。

## 7. 尚未定案

- 触发补练的证据数量、复练频率与占比；
- 使用几档难度以及各档的判断边界；
- 哪些情形允许延长某阶段、补课或改动 12 周细节；
- 多个薄弱项出现时如何排序；
- 跨领域覆盖如何长期监控，避免案例来源偏向影视或摄影；
- 自动化选题与推荐功能的实施方式。
