# 案例与参考素材

- [案例索引](index.md)：通过知识点、领域与训练关联查找正式归档的案例卡。
- [经典案例](classic/README.md)：可溯源的绘画、摄影、影视、平面设计等优秀作品资料。
- [个人案例](personal/README.md)：自己拍摄、制作或私人收藏的作品笔记。

原则：以**案例说明卡 + 来源 URL + 许可状态**为基本单位。仓库为公开状态，未获合法再分发授权的外部图片只保留链接及自己的笔记。媒体素材默认放本机 `local-assets/`，仓库内的 `materials/` 只保存 `.md` 案例资料卡及可公开的出处/路径信息。

**D-015 已确认**：先为近期课程维护少量跨领域候选链接，再按训练目标增补；只有真实使用过的案例才需形成完整资料卡。相同作品再次使用时更新同一案例卡的关联训练，不重复记录。详见 [案例获取与积累规范](../docs/11-case-acquisition.md)。

详细规范：[docs/05-asset-management.md](../docs/05-asset-management.md)、[本地素材存储](../docs/12-local-asset-storage.md)、[元数据和双向链接](../docs/13-metadata-and-indexing.md)；模板：[案例分析卡](../docs/templates/case-note.md)。
