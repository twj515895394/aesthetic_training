# 实战与训练记录

- [训练索引](index.md)：通过周次、知识点与主/对照案例回看训练。
- [daily](daily/README.md)：按 W01-D01 等命名的每日训练记录。
- [experiments](experiments/README.md)：标注、裁切、单变量实验、复刻或原创项目。
- [reviews](reviews/README.md)：每周/阶段复盘与改进。

训练追求**留痕可复现**：注明目标、原始案例、改动、结果和个人判断，不追求每天产出大作品。

**D-016 本地优先**：实验记录与复盘文字存仓库（Markdown）；原图、标注、裁切、调色和视频等媒体素材建议放本地 `local-assets/practices/Wxx-Dxx/`，不会随 Git push 同步。训练文件只记录可以公开的来源 URL、案例 ID 和相对本地路径。详见 [本地媒体管理](../docs/12-local-asset-storage.md)。

**D-017 关联检索**：在训练文件的 YAML 中填 `main_case_id`、`compare_case_id`、`related_concepts` 和标签；审核入库后更新两端的 Markdown 链接。见 [元数据与索引规范](../docs/13-metadata-and-indexing.md)。
