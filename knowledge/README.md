# 视觉审美知识卡

每个概念单独建卡：用自己的话解释、关联跨领域案例、记录实验、列出适用边界与反例。复制 [知识卡模板](../docs/templates/concept-card.md) 开始。

[知识点索引](index.md) 采用已确认的 D-017 机制：以稳定概念 ID、YAML `cases`/`sessions` 及指向真实案例卡和训练笔记的双向 Markdown 链接进行复用。字段细则见 [元数据规范](../docs/13-metadata-and-indexing.md)。

建议首批概念：visual-focus（视觉焦点）、visual-hierarchy（视觉层级）、negative-space（留白）、composition（构图）、lighting（光影）、color-contrast（色彩对比）。仅创建用到的知识卡，不预先堆叠空白词条。
